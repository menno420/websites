For the Anthropic Claude Code team

One person, eight Claude Projects, two weeks — the program reviewing itself.

From 2026-07-07 to 2026-07-21 one owner, who does not code, ran a fleet of Claude Code Projects — eight standing ones after a mid-program consolidation — across about twenty repositories, coordinated through committed git files alone. This site is that program's public review of itself for the Claude Code team. The program ended; the Project seats no longer exist; every claim here links to a public commit, and the problems get the same specificity as the successes.

What this was, in one minute

A Project was a claude.ai Code Project: one instruction box pasted once and delivered verbatim to every agent it spawned, a coordinator chat, and the worker sessions the coordinator started. Each Project owned one or more repositories. The owner's day was a reset-and-repaste of every Project each morning, a shared continuation prompt every few hours, and "continue" whenever a Project claimed its queue was exhausted. Sessions could not talk to each other, so orders travelled as numbered blocks appended to a file in each repo, and each session's last act was to overwrite a heartbeat file. What the program shipped, what broke, and what the owner would tell the product team are on the pages below; the words in bold are defined in the glossary.
